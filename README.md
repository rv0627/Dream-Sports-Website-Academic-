## Dream Sports

Dream Sports is a PHP-based e-commerce web application for buying and selling sports products. It provides a user-friendly platform for users to browse, search, and purchase sports equipment, as well as manage their profiles and orders. The application also includes an admin panel for managing products and users.

### Features
- User registration and login
- Browse and search sports products
- Add items to cart and watchlist
- Purchase history tracking
- User profile management
- Admin panel for product and user management
- Password reset and email notifications
- Responsive UI with Bootstrap

### Setup Instructions
1. Clone the repository:
	```
	git clone https://github.com/rv0627/Dream-Sports-Website-Academic-.git
	```
2. Place the project in your web server directory (e.g., `htdocs` for XAMPP).
3. Import the database (if provided) into your MySQL server.
4. Update `connection.php` with your database credentials.
5. Open the project in your browser (e.g., `http://localhost/Dream Sports`).

### Usage
- Register as a new user or sign in.
- Browse products, add to cart or watchlist, and make purchases.
- Admins can log in to manage products and users.
